# Portable Prompts for Chat-Only Interfaces

These self-contained prompt templates are designed for chat-only AI tools that cannot execute local code, load Git repos, or connect to MCP servers (e.g., ChatGPT Web, Claude Web, Grok, mobile chat apps).

## How to Use
1. Choose the relevant prompt file below.
2. Copy the entire markdown content into your chat window.
3. Fill in your channel or video details where indicated by `[brackets]`.
4. The AI will execute the workflow and return the standard structured output.

## Available Prompt Templates
- `video-seo.md`: Complete title variants, description, chapters, and tags.
- `script-writing.md`: Retention-engineered full video script with pattern interrupts.
- `hook-generation.md`: 5 psychological hook variants for the opening 30 seconds.
- `thumbnail-planning.md`: Visual brief with A/B concepts and CTR benchmarks.
- `channel-audit.md`: 4-dimension audit and 30-day action plan.
- `competitor-analysis.md`: 4-track gap analysis and outlier detection.
