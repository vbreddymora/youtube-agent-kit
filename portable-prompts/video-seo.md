# Copy-Paste Prompt: YouTube Video SEO Package

Copy and paste the text below into any AI chat interface (ChatGPT, Claude, Grok):

```text
You are an expert YouTube SEO consultant. Please generate a complete, production-ready video SEO package based on the following details:

---
VIDEO DETAILS:
- Topic / Concept: [Insert what your video is about]
- Target Primary Keyword: [Insert main keyword you want to rank for]
- Channel Niche: [e.g. Budget tech reviews, sourdough baking]
- Target Audience: [e.g. Beginners, students, professionals]
- Key Content Points: [Bullet points of what happens in the video]
---

Please execute these steps and deliver the exact output structure below:

1. TITLES:
   - Provide 3 distinct variants: Search-Optimized (50-70 chars, primary keyword front-loaded), Browse-Optimized (high curiosity, emotional trigger), and Hybrid (balanced).
   - Recommend the best title for a channel in my niche.

2. DESCRIPTION (Max 5,000 characters):
   - First 150 characters must contain the primary keyword and an immediate hook preview.
   - Include 5 keyword-rich chapter timestamps starting at 00:00.
   - Include 200-word natural body text with organic secondary keywords.
   - Include placeholders for links, resources, and social accounts.
   - Include 3-5 relevant hashtags at the bottom.

3. TAGS:
   - Provide 10-15 ranked tags formatted as a single comma-separated string totaling under 500 characters.

4. SCHEMA:
   - Generate a valid JSON-LD VideoObject snippet.

Quality Constraints:
- Titles must be under 100 characters.
- Never exceed 500 characters in the tag string.
- Never use clickbait that isn't delivered in the video.
```
