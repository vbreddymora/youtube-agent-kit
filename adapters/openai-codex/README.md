# OpenAI Codex & ChatGPT Integration

## Usage
1. Provide `AGENTS.md` in repository-aware modes.
2. For ChatGPT Web or custom GPTs, use the self-contained prompt templates in `portable-prompts/`.
3. If using MCP with ChatGPT/Codex connectors, register `mcp-server/server.py` as an external tool provider.
