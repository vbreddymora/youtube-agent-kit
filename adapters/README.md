# Multi-Agent Compatibility Adapters

This directory provides thin, native integration guides and configuration files for target AI coding assistants and agent environments.

## Supported Targets

| Tool | Integration Type | Location |
|:---|:---|:---|
| **Claude Code** | Native Plugin & Orchestrator | `adapters/claude-code/` |
| **Cursor** | `.cursorrules` & MCP Config | `adapters/cursor/` |
| **Google Antigravity** | Workspace Agent Skills & MCP | `adapters/antigravity/` |
| **Gemini CLI** | System Prompts & Tool Calling | `adapters/gemini/` |
| **OpenAI Codex / ChatGPT** | Custom Instructions & Tool Calling | `adapters/openai-codex/` |
| **Chat-Only Web Interfaces** | Standalone Prompts | `portable-prompts/` |
